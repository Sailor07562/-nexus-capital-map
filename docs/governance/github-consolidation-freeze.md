# GitHub Consolidation Freeze

Anchor: #ANCHOR-NEXUS-GITHUB-CONSOLIDATION-STRUCTURE-001

Status: STRUCTURE FROZEN

## Purpose

Create a stable repository structure for Nexus artifacts so SQL migrations,
governance documents, engine/lane specs, backup notes, workflow exports, and
handoff prompts stop being scattered across chats.

## In Scope

- SQL migrations
- Schema snapshots
- Governance documents
- Engine and lane specs
- Carryover and handoff prompts
- Backup manifests and restore notes
- n8n workflow exports
- Tracker, Airtable, Docker, and PostgreSQL integration notes
- Read-only verification checks

## Out of Scope

- Passwords
- API keys
- Private credentials
- Raw sensitive financial data
- Unfiltered database dumps
- Account exports
- Tokens
- Files that can move money or expose identity/account details
