# Nexus GitHub Consolidation Carryover

Anchor: #ANCHOR-NEXUS-GITHUB-CONSOLIDATION-STRUCTURE-001

Mission:
Use GitHub as the consolidation layer for Nexus code, SQL, governance docs,
backup notes, engine/lane files, operating protocols, and handoff prompts.

Current status:
- Repo structure is frozen.
- GitHub is for consolidation, traceability, rollback, and collaboration.
- GitHub does not replace PostgreSQL, Drive, Tracker, Airtable, Docker, n8n, or
  Work Mode.
- No database work is authorized without capability verification.

Startup:
1. Declare operating mode.
2. Verify repo folder and Git status.
3. Verify GitHub authentication before push/pull.
4. Verify PostgreSQL only if database work is requested.
5. Do not claim execution without tool output.
